# Maintainers

A repository maintainer is a committer with the additional privilege of merging pull requests into the main branch of this repository.

## Current Maintainers

This repository is part of the [Kagenti](https://github.com/kagenti/kagenti) platform and shares the platform's maintainers. You can find the full list in the main repository's [MAINTAINERS.md](https://github.com/kagenti/kagenti/blob/main/MAINTAINERS.md) file.

## Becoming a Maintainer

For more details on the process of becoming a maintainer, see the [Governance](https://github.com/i-am-bee/community/blob/main/GOVERNANCE.md) document.
